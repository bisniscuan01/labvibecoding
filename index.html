Bangun PawonBoga dengan Vibe Coding

Dalam workshop ini, Anda membangun PawonBoga — katalog dan dashboard produk UMKM makanan-minuman secara bertahap menggunakan AI agent. Lengkap dengan empat pilihan tool AI, empat opsi hosting, checklist keamanan, dan rubrik penilaian interaktif.

🎯 Target akhir: lihat PawonBoga yang sudah jadi — inilah aplikasi yang akan Anda bangun langkah demi langkah. Source code referensi: github.com/bisniscuan01/pawonboga.

Setelah lab ini, Anda akan mampu:
  • Menulis spesifikasi (SPEC.md, UI-SPEC.md, TASKS.md) sebelum meminta AI menulis kode.
  • Membangun katalog dan dashboard CRUD lewat iterasi prompt kecil serta review git diff.
  • Menambahkan penyimpanan localStorage tervalidasi, import/export JSON, dan integrasi WhatsApp.
  • Menguji dengan test case manual dan Vitest, lalu melakukan audit keamanan dasar.
  • Men-deploy ke hosting statis dan mendokumentasikan batasan aplikasi dengan jujur.

Centang kotak di tiap langkah. Tanda disimpan di browser ini saja.

6 aturan emas

  1. Tulis spesifikasi sebelum kode.
  2. Satu prompt, satu tujuan.
  3. Minta rencana dulu, izinkan eksekusi sesudahnya.
  4. Baca perubahan (git diff) sebelum menyetujui.
  5. Uji di browser setelah setiap iterasi, lalu commit.
  6. Jangan pernah menempel kunci API atau data sensitif ke prompt.
